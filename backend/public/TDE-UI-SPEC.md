# TDE UI 设计规范 (TheDesignExpo UI System)

> 版本：v1.0 | 基准：designfesta.com 视觉风格 | 状态：已锁定

本规范为 TheDesignExpo 品牌的唯一 UI 标准。所有页面、子站、衍生页面必须严格遵循本规范，不得擅自更改配色、字体、组件样式或布局结构。

---

## 一、设计哲学

- **风格定位**：活泼、多彩、卡通感的国际艺术节视觉，区别于极简黑白风
- **核心气质**：热闹、自由、无门槛、创作者友好
- **参考原型**：designfesta.com 首页结构与视觉语言
- **禁止**：极简黑白、性冷淡风、玻璃拟态、紫蓝渐变科技风

## 三、字体系统（Typography）

### 字体栈

```css
font-family: 'Space Grotesk', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif;
```

- **英文展示/正文**：Space Grotesk（weights: 400, 500, 600, 700）
- **中文**：Noto Sans SC（weights: 300, 400, 500, 700, 900）
- **字体加载**：必须走 `https://miaoda.feishu.cn/fonts/css2` 自托管镜像

### 字号层级

| 元素 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero 主标题 | clamp(42px, 9vw, 110px) | 900 | 行高0.95，字间距-0.03em |
| 区块大标题 | clamp(28px, 6vw, 56px) | 900 | |
| 卡片标题 | clamp(22px, 3vw, 30px) | 900 | |
| 正文 | 15-17px | 500-600 | 行高1.6-1.9 |
| 标签/小字 | 11-13px | 700 | 字间距0.1-0.25em，大写 |
| 数据数字 | clamp(40px, 6vw, 72px) | 900 | 黄色，深蓝底 |

## 四、组件规范（Components）

### 4.1 按钮（.btn-festa）

```
样式：3px 实线黑色边框 + 底部 4px 黑色阴影
圆角：8px
内边距：16px 40px
字号：15px，字重700
hover：上移2px，阴影变为2px
变体：
  - .primary → 红色底(#E53935) 白字
  - .secondary → 白底 黑字
```

### 4.2 出展形式详情按钮（.format-btn）

```
样式：3px 黑边 + 底部4px黑阴影
圆角：8px
内边距：16px 48px
字号：16px，字重700，白字
颜色：按7种形式固定映射（见配色表）
hover：上移2px，阴影2px
```

### 4.3 卡片（.format-card / .event-info-card）

```
边框：3px 实线 #222
圆角：12px
阴影：6-8px 偏移，rgba(0,0,0,0.08-0.1)
背景：白色
```

### 4.4 活动信息键值对（.event-info-row）

```
左侧标签：宽140px，浅黄底(#FFF3B0)，居中，字重700
右侧内容：flex:1，padding 20px 28px，字重600
分隔：底部2px #f0f0f0
```

### 4.5 参观信息按钮（.visitor-btn）

```
背景：浅黄(#FFF3B0)
边框：2px #F5D000
圆角：12px
内边距：18px 24px
字号：17px，字重700
图标：左侧24px emoji/符号
hover：白底，右移4px
高亮态(.highlight)：深黄底(#F5D000)，黑边
```

### 4.6 顶部导航（.topbar）

```
高度：64px（手机56px）
背景：白色
底部边框：3px 黄色(#FFE600)
阴影：0 2px 8px rgba(0,0,0,0.06)
布局：左侧汉堡按钮，居中Logo，右侧语言切换
```

### 4.7 Logo（.topbar-logo）

```
徽章：48x48px圆形，黄底(#FFE600)，3px黑边，字重900
文字：
  - 副标题：10px，字重700，字间距0.25em，"INTERNATIONAL ART EVENT"
  - 主标题：22px，字重900，"THEDESIGN EXPO"
```

### 4.8 汉堡菜单按钮（.hamburger-btn）

```
三横线：28x3px，黑色，圆角2px
下方文字：11px，字重700，字间距0.1em
点击后滑出左侧抽屉菜单（宽300px）
```

### 4.9 语言切换（.lang-toggle-top）

```
位置：顶部栏右侧
样式：2px黑边，圆角20px
按钮：padding 5px 12px，11px，字重700
激活态：黑底白字
手机端：隐藏，改为左下角悬浮按钮
```

## 五、页面区块规范（Sections）

所有页面必须按以下顺序和样式组织区块：

### 5.1 Hero 区
- 背景：粉→黄→紫→蓝 135度线性渐变
- 叠加：45度斜纹半透明白色纹理
- 内容：圆形徽章 → "INTERNATIONAL ART EVENT" 眉标 → 超大标题 → 副标题 → 双按钮
- 底部：SCROLL 箭头动画提示

### 5.2 活动信息卡
- 白色卡片，3px黑边，8px偏移阴影
- 顶部黄色标题栏
- 5行键值对（名称/日期/时间/场地/展位）

### 5.3 参观信息卡
- 黄色大卡片，3px黑边
- 顶部标题栏
- 6个浅黄圆角按钮（门票/地图/搜索/等候线/跑道/参展商名单）

### 5.4 出展者募集中
- 粉色背景(#FFCDD2)
- 超大标题（#D84315）
- 描述文字 + 红色CTA按钮

### 5.5 7种出展形式
- 背景：绿→浅绿 垂直渐变
- 标题：带左右斜线装饰
- 7张竖排白色卡片，每张：16:9大图 → 编号标签 → 标题 → 描述 → 彩色详情按钮
- 卡片间距32px

### 5.6 理念/关于
- 白色背景
- 大标题 + 引言（蓝色，加粗）+ 16:9图片 + 段落文字

### 5.7 数据区
- 深蓝背景(#283593)
- 3列网格（手机单列）
- 黄色大数字 + 白色描述

### 5.8 媒体报道
- 浅黄背景(#FFF3B0)
- 白色卡片列表，每张：日期(蓝) + 标题 + 黄色标签来源
- hover：右移6px + 阴影

### 5.9 联系区
- 白色背景
- 双栏：左侧黄色信息卡，右侧白色表单卡
- 表单按钮：红色，3px黑边+阴影

### 5.10 页脚
- 深灰/黑背景(#222)
- 4列：品牌 + 导航 + 出展者 + 参观者
- 黄色小标题
- 底部版权 + 社交图标

## 六、响应式断点

| 断点 | 设备 | 关键变化 |
|---|---|---|
| > 900px | 电脑/平板横屏 | 完整布局，双栏，3列数据 |
| ≤ 900px | 平板 | 联系区单栏，数据单列，页脚2列 |
| ≤ 640px | 手机 | 顶栏56px，语言切换变悬浮按钮，信息标签100px宽，按钮全宽，出展形式卡片padding缩小 |

---

## 七、交互规范

- **抽屉菜单**：左侧滑入，黑色半透明遮罩，点击链接自动关闭
- **平滑滚动**：所有锚点链接 smooth scroll，偏移64px（顶栏高度）
- **按钮hover**：上移2px + 阴影缩短
- **卡片hover**：右移/阴影变化
- **表单提交**：按钮变绿色"已发送"，2秒后恢复
- **无障碍**：支持 `prefers-reduced-motion`

---

## 八、图片规范

- 所有图片使用 CDN 远程 URL，禁止本地路径
- 出展形式配图：16:9 横图，真实场景摄影风格
- Hero 区：纯CSS渐变，不使用图片
- 图片需与对应出展形式内容匹配

## 十、复用规则

1. 新建任何 TheDesignExpo 相关页面时，**必须**复制 `TDE-template.html` 作为起点
2. 不得更改 CSS 变量中的颜色值
3. 不得更改组件的边框/阴影/圆角规格
4. 新增区块必须插入到第五章规定的顺序中，或在页脚前追加
5. 中英文双语必须完整覆盖所有文本（data-i18n 属性）
6. 响应式必须覆盖三个断点
