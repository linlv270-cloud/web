# 消费者城市探照首页历史探讨稿

更新日期：2026-08-22

> 版本状态：历史原型规则，不是当前体验版发布基线。当前发布基线见 `README.md`、`LAUNCH_READINESS.md` 和 `docs/miniapp-vi-standard.md`，采用 Content-first 内容发现流与四栏底部导航。

## 消费者流程

1. 顶部表头显示 Logo、品牌名、口号和“我的”。
2. 用户先在“从哪里出发？”选择省、市，不选择区县。
3. 用户点击底部唯一按钮“马上探照新遇”。
4. 探照灯扫描城市项目卡片，随后展示一项随机结果。
5. 结果可进入原自助材料包详情或原陪玩官体验项目详情。
6. 再次探照时不立即重复上一项；抽取同时兼顾不同体验点和陪玩官的展示公平。
7. “我的”保留最近探到、收藏、分享、申请或管理陪玩官身份。

## 保留边界

- 关闭的是消费者端“自助玩 / 陪你玩”独立入口，不删除源页面和业务数据。
- 自助材料包、教程、店内规范、体验点和后台管理继续保留。
- 陪玩官项目、档案、日期、详情、客服入口和后台审核继续保留。
- 创作者提交和运营台仍明确区分两类内容，只有消费者发现入口合并为一个城市抽取池。
- 未开通城市显示“请帮我们找到这座城市的奇灯陪玩官”，并提供申请与静态客服入口。

## 视觉边界

- 保留当前米白、薄荷绿、奶油黄和硬边框品牌风格。
- 只有探照舞台使用深色背景，不能把整个小程序改成黑色风格。
- 表头和底部主按钮必须避开微信胶囊与手机安全区。
