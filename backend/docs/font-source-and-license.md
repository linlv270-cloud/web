# Qideng Editorial font source

`Qideng Editorial` is a character subset derived from Adobe Source Han Serif SC Medium 2.003.

- Upstream project: https://github.com/adobe-fonts/source-han-serif
- Upstream copyright: Copyright 2017-2024 Adobe
- Upstream reserved font name: `Source`
- License: SIL Open Font License 1.1, included in `docs/licenses/OFL-1.1.txt`
- Included subset: `public/fonts/qideng-editorial-subset.woff`
- Character manifest: `design-system/editorial-glyphs.txt`

The subset has been renamed to `Qideng Editorial` so the modified font does not use the upstream reserved font name. It is used only for the brand name and stable editorial headings. Body text, controls, and user-generated content use the system sans-serif stack.
