# 奇灯 new1.0 UI / VI 合同

## 版本边界

- `new1.0` 基于冻结版 `08232330v1 / 0.28.2-forest`。
- 本版只改变 UI、VI、可见文案、图标和由布局产生的控件形式。
- 路由、接口、数据库字段、身份、权限、筛选、日期、审核和企业微信链路不得改变。
- 数值唯一来源为 `design-system/qideng-tokens.json`，页面不得自行创建字号、颜色、圆角或字重。
- 正式风格为 **Atmospheric Content-first / Sculpted Detail**，中文简称“氛围内容优先 / 雕刻感细节”。

## 品牌与语言

- 品牌锁定组合：`奇灯 COCOC`。
- 口号：`在城市里，发现一次新遇`。
- 消费导航：`发现 / 自在 / 结伴 / 我的`。
- 角色名称：`奇灯新遇官 / COCOC HOST`。
- 可见词汇使用“体验、发布体验、体验项目封面、申请代表图、体验详情、联系新遇官、推荐栏目申请”。
- `new1.0` 不提供用户转发、朋友圈分享、分享海报或保存海报入口，右上角分享菜单保持关闭。
- `project`、`creator` 等代码标识和“项目场景”等历史数据键不得因文案替换而改名。
- 英文只用于品牌、眉题和极少量专题，不进入密集表单和底部导航。

## 全幅画布

- 消费页面使用真正的上下通幅、左右通幅画布，不在手机页面内再放一个大圆角外壳。
- 背景和首图可抵达屏幕边缘；文字、按钮和列表保留 `32rpx / 16px` 安全边距。
- 固定品牌表头必须读取微信胶囊实际位置，始终处于最高层级，不遮挡、不失去点击区域。
- 发现、自在、结伴使用深色氛围背景；我的、表单、工作台和后台使用高可读明亮表面。
- 页面首屏应留下后续内容提示，不做占满整屏却没有下一步信号的静态封面。

## 字体

- 功能 UI、按钮、表单和正文：系统无衬线字体。
- “奇灯”、口号和固定栏目标题：实际加载 `Qideng Editorial`，它是思源宋体的授权轻量子集；不允许只声明字体名称却不加载字体文件。
- 体验名称、首图动态标题、创作者名称、通知标题等用户或后台动态内容：系统无衬线字体，避免轻量子集缺字和宋黑混排。
- 固定字阶：Display `44/60rpx`，Section `36/52rpx`，Card `34/48rpx`，Body `30/46rpx`，Secondary `28/42rpx`，Caption/Micro `24/36rpx`。
- 只允许 `400 / 500` 两档产品字重；标题不使用黑体式重粗。
- 字间距固定为 `0`，字号不得随视口宽度缩放。
- 图片文字使用暖柔白 `--on-dark`，中文标题至少 `500`，不得依赖纯白细字承担核心信息。

## 色彩与材质

- 基础色：暖雾白 `--paper`、柔白 `--surface`、浅灰绿 `--surface-soft`。
- 文字色：石墨灰 `--ink`、正文灰 `--text`、辅助灰 `--muted`，禁止纯黑正文。
- 品牌主色：灰绿 `--accent`；情绪强调：少量珊瑚 `--highlight`；真实状态使用成功、警告、危险和信息色。
- 不以紫色为主，不把页面做成单一绿色色阶；图片承担主要色彩，UI 保持克制。
- 玻璃表面只使用 `--glass-light / --glass-strong / --glass-dark`，不添加装饰性渐变和离散光球。
- 层级依靠透明度、明度、留白和细线，不依靠厚重阴影。

## 网格与留白

- 最小节奏为 `8rpx / 4px`；页面安全边距为 `32rpx / 16px`。
- 标题到内容通常 `24rpx`；卡片间 `16-24rpx`；主要区块间 `64-80rpx`。
- 所有标题、图片、列表和字段标签落在同一左对齐线。
- 禁止卡片套卡片；页面区块保持无框，卡片只用于重复内容、弹窗和真正需要边界的工具。
- 禁止在有内边距的容器中使用 `100vw`；任何页面都不得横向溢出。

## 圆角、线与图标

- 小圆角 `8rpx / 4px`，常规圆角 `16rpx / 8px`，大型弹层顶部圆角 `32rpx / 16px`。
- 熟悉的纯图标按钮使用正圆；普通文字按钮不得做成无意义胶囊。
- 结构线固定 `1rpx / 1px`，极少数高密度控件允许 `2rpx`，只使用语义线色。
- 图标统一使用同一套线性图标，常规 `36-40rpx`，导航 `40rpx`，触控区至少 `88rpx / 44px`。
- 不用 Emoji、数学字符或临时绘制图形代替功能图标。

## 图片与原创背景

- 体验卡片、体验项目封面和申请代表图固定 `4:5`；Logo 固定 `1:1`；必要的场地辅助图允许 `3:2`。
- 图片始终在自己的裁切框内，禁止溢出页面或拉伸变形。
- 首页横向精选露出下一张约 `15%`；在图片区纵向拖动必须继续滚动页面。
- 背景必须原创生成或有明确授权；当前三张原创资产由种子化程序从零生成，不含参考图像素。
- 背景仅提供气氛，不承载需辨认的人物、地标、品牌和文字。

## 控件与状态

- 主按钮：灰绿底、暖白字；次按钮：明亮表面和细线；图标按钮只用于明确工具命令。
- 表单字段最小高度 `88rpx / 44px`，字段名在上，帮助和错误信息在下。
- 标签选中态使用浅灰绿表面、深灰绿文字和明确状态，不靠高饱和彩色铺满。
- 所有控件必须覆盖默认、按下、选中、禁用、加载、成功、失败和空状态。
- 筛选底部抽屉、法律文档和长表单使用实体高可读表面，不为了“玻璃感”牺牲阅读。

## 动效

- 按下反馈 `140ms`，标准切换 `280ms`，抽屉和复杂过渡 `460ms`。
- 动效只使用系统缓动和 `transform / opacity`，避免布局重算和滚动卡顿。
- 动画应立即响应并缓慢收住，不通过无反馈延迟制造重量。
- 尊重系统“减少动态效果”；横向卡片使用原生惯性，不拦截纵向页面滚动。

## 验收门槛

- 每个注册页面至少检查 `320x568`、`375x812`、`390x844` 三种视口。
- 必查顶部安全区、左右边界、文字换行、图片比例、底栏、键盘遮挡、手势方向和触控尺寸。
- 发布前必须通过设计系统、类型、内容合同、业务规则、上线检查和完整测试。
- 自动检查必须阻止旧品牌口号、旧角色称谓、旧导航名称、纯黑重字和页面级任意视觉值回归。
