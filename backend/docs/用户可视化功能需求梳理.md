## 一、功能概述

在「用户管理」页的筛选结果区，新增一个「可视化」按钮。点击后，基于**当前已选用户**，为每个用户自动生成一页 **PPT 风格的 PNG 图片档案**，包含用户照片、标签、介绍、个人 logo 和奇灯品牌 logo，并支持将所有页面打包成 ZIP 下载。

---

## 二、按钮位置与样式

**当前按钮组（从左到右）：**
```
[ + 新增用户 ]  [ 通知已选用户 ]  [ 下载全部资料 ]
```

**新增后：**
```
[ 可视化 ]  [ + 新增用户 ]  [ 通知已选用户 ]  [ 下载全部资料 ]
```

- 位置：「新增用户」**左侧**
- 样式：次要按钮（白色描边，与「通知已选用户」「下载全部资料」一致）
- 图标：图片/网格类图标

---

## 三、触发逻辑

1. 用户在筛选区设置条件 → 点击「开始搜索」得到筛选结果列表
2. 用户**勾选**需要可视化的用户（已选用户）
3. 点击「可视化」按钮
4. 系统读取**已选用户**的完整数据
5. 为每个用户生成一页 PPT 图片（16:9 PNG）
6. 弹出预览 → 点击「下载」打包成 ZIP

**范围确认：** 仅针对「已选用户」，不是全部筛选结果。
**数量上限：** 单次最多 50 人，超出提示「已选超过 50 人，请缩小选择范围」。

## 六、下载方案（已确认）

- 每个用户生成 **1 张 PNG**（16:9，1920×1080）
- N 个已选用户 → N 张 PNG → 打包成 **ZIP** 下载
- 下载按钮**单独做**（在可视化预览弹窗内），不与现有「下载全部资料」按钮混用
- ZIP 文件名：`奇灯用户可视化_20260829_13人.zip`
- 内部单张命名：`01_用户名.png`、`02_用户名.png` ……

## 七、技术实现路径（前端方案）

### 7.1 技术栈
- 运营台是 Next.js 项目，纯前端实现
- `html2canvas`：DOM 转 PNG 图片
- `jszip`：多张 PNG 打包成 ZIP

### 7.2 实现步骤
1. **新增「可视化」按钮**：在筛选结果区按钮组最左侧
2. **已选用户校验**：点击按钮后检查已选数量（0 人提示「请先选择用户」，>50 人提示上限）
3. **获取用户数据**：调用现有用户详情/列表 API，拿到已选用户的完整数据（含 workUrls、logoUrl、intro、tags 等）
4. **渲染 PPT 模板**：用隐藏 DOM 容器，按 16:9 布局循环渲染每个用户
5. **转图片**：html2canvas 逐页截图生成 PNG
6. **预览弹窗**：展示生成的图片缩略图，提供「下载 ZIP」按钮
7. **打包下载**：jszip 打包 → 触发浏览器下载
8. **加载状态**：生成过程显示进度条（如「正在生成 3/13…」）

### 7.3 注意事项
- 图片跨域：workUrls/logoUrl 图片域名需支持 CORS（html2canvas 需要），否则用 `useCORS: true` 或代理
- 字段缺失：用户没上传照片/logo/intro 时，用占位图或隐藏区域，不能报错
- 字体加载：确保 html2canvas 渲染时中文字体已加载完成
