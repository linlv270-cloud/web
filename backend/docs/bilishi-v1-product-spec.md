# 彼此的彼里市 V1 产品规格

## 1. 品牌与定位

- 品牌全称：彼此的彼里市
- 界面简称：彼里市
- 品牌记忆句：彼此的彼，邻里的里，城市的市。
- 核心口号：来彼里市，做兴趣公民。
- 品牌主张：兴趣即彼岸。
- 产品定位：一张由真实的人共同搭建的同城兴趣生活地图。
- 功能表达：找到同频的人，也让你的兴趣被看见。
- 微信首版类目表达：同城兴趣活动与生活服务。
- 首版只提供一对一咨询，不提供公开动态、陌生人群聊或开放式社交广场。

## 2. 账号与身份

- 使用一套微信账号体系，不让用户在注册时二选一。
- 所有用户默认是“兴趣公民”，可浏览地图、认领兴趣、咨询、收藏和分享。
- 任何兴趣公民都可申请成为创作者。
- 通过申请后，在同一账号上增加创作者权限，不创建第二个账号。
- “我的”提供“逛彼里市 / 管理我的兴趣地”入口。
- 普通消费者的头像和资料不自动公开。
- 只有已申请成为创作者、资料达到展示要求并同意公开的人，才显示在兴趣地图上。

## 3. 兴趣地图

- 首页基于真实城市行政区边界绘制地图，V1 只展示到区级，不展示街道、建筑、商户、道路和门牌。
- 默认先显示城市总览；每个区块同时显示区名、公开创作者数和近期计划数。
- 点击某个区后，再显示该区创作者照片和“一句话介绍”气泡；点击创作者进入档案和近期计划。
- 创作者只通过六位行政区代码关联区块，不采集、保存或公开用于前台展示的精确个人经纬度。
- 头像只表达“位于该区”，不得暗示头像所在位置就是创作者的具体地址。
- 具体见面地点由用户与创作者在一对一咨询或企业微信中确认。
- 定位只用于建议省、市、区；拒绝定位时允许手动选择，不因拒绝定位阻断浏览。
- 地图筛选至少包括省、市、区、日期和兴趣标签。
- 地图边界加载失败时自动显示区县列表，页面不得空白，也不得阻断筛选和随机推荐。
- 生产环境使用合规地图服务或合法行政区边界数据，并按中国大陆地图合规要求处理；原型数据不得直接视为生产数据源。
- 启动页和分享卡片可以继续使用抽象兴趣街区作为品牌视觉，但不能与真实位置混淆。
- 区块颜色、统计标签、首页图片和文字由超级管理员维护；真实行政边界不允许管理员随意手绘修改。
- “随便逛逛”在当前城市、区、日期、兴趣条件内随机匹配。
- 随机推荐需要排除近期已经展示的结果，并兼顾新创作者曝光，不能固定重复同一人。

## 4. 资料字段

以下核心资料必须继续存在，不能因新版地图而删除：

- 邀请码与完整来源关系
- 手机号
- 微信 ID
- 品牌 / 工作室 / 产品名称
- 省、市、区
- 上传图片及裁剪结果
- 一句话介绍（用于地图说话气泡）
- 完整文字介绍
- 标签及用户申请新增标签
- 合作方式 / 合作需求
- 日期计划起止日期
- 近期无计划
- 活动期间仍可接受平台邀请
- 活动图片和活动一句话介绍
- 管理员分级：优秀、良好、一般、差
- 管理员内部备注

超级管理员可配置每个前台字段是否启用、必填或选填，以及字段名称和提示文字。

## 5. 兴趣公民端

建议底部导航：地图、奇遇、消息、我的。

核心流程：

1. 新用户第一次进入时，看到品牌、城市和位置授权说明，并完成兴趣认领。
2. 首次引导完成后，以及用户以后每次重新打开小程序时，首页直接显示当前城市的真实区级兴趣地图。
3. 首页地图默认显示全市各区、公开创作者数和近期计划数。
4. 点击某个区块后，在首页下方显示该区创作者照片和“一句话介绍”。
5. 点击创作者，或使用“随便逛逛”进入揭晓结果和详情。
6. 查看创作者档案、标签、日期计划和活动详情，并发起一对一咨询。
7. 收藏、分享或继续探索。
8. 在“我的”中查看兴趣、收藏、咨询、官方客服和创作者申请入口。

## 6. 创作者端

建议底部导航：档案、回复、通知、我的。

- 档案：图片、一句话介绍、完整介绍、省市区、标签、合作方式、日期计划和活动资料。
- 回复：用户的一对一咨询，显示未读数与超时状态。
- 通知：资料问题、平台意见、审核变化和系统公告。
- 我的：邀请码、分享关系、手机号、密码、官方客服和切回兴趣地图。
- 日期计划必须支持起止日期、“近期无计划”和“活动期间仍可接受邀请”。
- 平台默认公开活动数量为 1，超级管理员可按创作者调整上限。

## 7. 管理后台保留范围

现有超级管理员与管理员能力全部保留。新版只调整品牌与前台组织方式，不删除后台模块。

保留及扩展的后台模块：

1. 运营概览
2. 用户资源看板
3. 用户管理及代填资料
4. 管理员账号审核、暂停和权限范围
5. 邀请码与完整关系树
6. 标签管理、用户新增标签复核、替换和合并
7. 平台通知和超级管理员短信通知创作者
8. 文章生成管理
9. 红薯算法设置
10. 趋势词库
11. 首页展示和品牌文字
12. 页面字段设置及必填 / 选填控制
13. 活动与审核
14. 咨询与客服超时规则
15. 省、市、区、日期、标签、分级和合作需求统计
16. 真实区级地图、公开创作者、地图视觉和随机规则管理

## 8. 权限边界

### 超级管理员

- 查看和编辑全平台用户与创作者。
- 代用户维护全部资料字段。
- 审核、暂停和管理管理员账号。
- 查看完整邀请码关系树。
- 配置字段、标签、地图、活动、首页、咨询超时和创作者活动上限。
- 按条件发送站内通知和短信。
- 多选、全选和导出用户资料。
- 查看全平台统计缓存与明细。

### 管理员

- 仅查看自己邀请码关系树下的用户。
- 可手动新增用户并代用户维护图片、城市、区、日期、标签、介绍、合作需求、分级和备注。
- 可维护自己用户的活动与咨询超时设置。
- 可查看自己的固定邀请码及用户邀请码。
- 无下载导出权限。
- 无平台通知和短信发送权限。
- 无全平台字段、标签、地图和品牌设置权限。

## 9. 视觉原则

- 前台地图使用真实行政区边界作为信息骨架，并将其处理为无建筑、无商户、无次要道路的大块扁平色面。
- 抽象兴趣街区只用于启动页、分享页和品牌装饰，不用于表达真实位置。
- 使用“彼岸绿”为品牌主色，并使用黄色、玫红、蓝色等少量街区辅助色，避免单一绿色界面。
- 地图区块负责城市与区域信息秩序，真实人物和活动照片负责情绪。
- 人物照片可保留颗粒、轻微模糊和温暖城市电影感。
- 动效缓慢、克制，使用区块选中、头像出现和气泡展开，不使用快速抽奖动画。
- 正式品牌露出使用“彼此的彼里市”，紧凑导航可使用“彼里市”。

## 10. 上线原则

- 北京服务器现有网站保持运行，旧版本和备份不删除。
- 新版使用独立目录、数据、端口、服务和域名部署。
- 原型确认后再修改正式小程序代码。
- 完成真机测试、权限测试、数据迁移演练、备份恢复测试和微信审核后再发布。
