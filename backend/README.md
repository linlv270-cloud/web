# 奇灯

奇灯小程序与运营台正式工程。

本工程由旧项目 `qideng-mini-program-platform` 迁移而来，目标是复用旧平台能力并实现当前确认的“奇灯”业务。

当前消费者主线：

- 首页采用 `Soft-minimal / Content-first` 内容优先发现流，图片使用稳定的 4:5 比例。
- 消费者底栏固定为“发现 / 自助玩 / 陪你玩 / 我的”，两条体验路径独立浏览、独立进入详情。
- 首页展示本周精选、今日发现和平台运营栏目，不提供搜索入口。
- “更多探索”支持体验方式、使用场景、日期和“或许喜欢的”；未选日期时只展示未来有日期的陪你玩项目，选定日期后精确匹配。
- 城市由用户手动选择省和市；未开通城市显示陪玩官申请和“联系奇灯”入口。

当前品牌口径：

- 产品名：奇灯
- 口号：兴趣是试着玩出来的
- 玩法：城市兴趣发现（内容来源为自助玩 / 陪你玩）
- VI：森林编辑式内容优先极简，以图片为视觉主体，灰色文字与低饱和森林绿作为主语言，灯光黄只用于特殊状态；不使用厚边框、重阴影和手绘装饰。

已完成：

- 跳过 `node_modules`、`.next`、测试临时数据和发布缓存。
- 更新工程名称和微信开发者工具描述。
- 完成城市选择、内容发现流、独立体验列表、详情与创作者端正式结构。
- 完成体验点、材料包、教程、项目日期、运营栏目和新遇官注册手机号直联入口。
- 完成超级管理员、子管理员、创作者与消费者权限回测。
- 移除积分、券、核销、在线预约、下单和库存管理入口。

当前自助玩只维护“体验点可体验哪些材料包”的关系，不记录库存数量、出入库或预警。陪你玩只展示项目日期并进入咨询，不创建预约订单或占用名额。

新遇官工作台的“通知”用于接收审核、项目状态和平台通知。消费者在结伴体验详情页点击“联系新遇官”后，先看到脱敏手机号和来源提示；连接微信身份后可主动查看、复制或拨打新遇官已授权公开的注册手机号，双方直接沟通，奇灯不接入或转发沟通内容。新遇官未单独授权公开注册手机号时，前台显示“暂未开放联系”。企业微信仅保留用于平台内部通知，不再承担消费者与新遇官的联系入口。

## 本地运行

要求 Node.js 22.13 以上。

```bash
npm ci
npm run dev
```

常用检查：

```bash
npm run design:sync
npm run check:design-system
npm run check:content-first
npm run check:all
npm run lint
npm run build
npm run test:mini
```

全站视觉与交互规范见 `docs/miniapp-vi-standard.md`，唯一发布令牌源见 `design-system/qideng-tokens.json`。页面样式不得直接写颜色、字号、字重或圆角；新增基础值必须先更新令牌源并重新生成接入文件。设计系统和内容发现版检查均位于本项目内，源码发布包解压后无需依赖同级原型目录即可完成全部检查与构建。
